# A Pink Christmas Garden for Love 🌷

A romantic pink Christmas-themed website built with plain HTML, CSS, and JavaScript.

## Preview
Open `index.html` in a browser. Keep the `photos`, `images`, and `audio` folders beside it.

## Add your voice recording
1. Record your message on your phone or computer.
2. Save/export it as an MP3 named exactly `love-voice-note.mp3`.
3. Put that MP3 inside the `audio` folder.
4. Open `index.html` — the player is already placed in the **Open when you need it** section, above the letter cards.

The audio file path used by the player is `audio/love-voice-note.mp3`.

## Personalize it
- Edit timeline dates and stories in `index.html`.
- Replace the sample love-letter messages with your own words.
- Update quiz questions and answers in the `quiz` array.
- Replace captions or photos in the `photos` folder, keeping filenames the same.
- CHRISTMAS GIFT IMAGE: replace `images/replace-this-with-your-gift.svg` with your own image, or update its image src in the surprise-button code.

## Publish for free
Upload the complete folder (including `photos`, `images`, and `audio`) to a GitHub repository and enable GitHub Pages in Settings → Pages. Do not upload only `index.html`.
